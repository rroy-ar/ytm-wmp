# Development skin

This is an original, deliberately plain skin used when `-skin` is not supplied.
It exists so the player works out of the box without bundling a copyrighted
Winamp skin.

The loose BMPs and color configs use classic Winamp 2.x sheet dimensions and coordinates:

| File | Size | Purpose |
|------|------|---------|
| `main.bmp` | 275x116 | main-window background |
| `titlebar.bmp` | 344x87 | active/idle title bars, shade bar, clutter bar |
| `cbuttons.bmp` | 136x36 | transport buttons, normal and pressed |
| `shufrep.bmp` | 92x85 | shuffle, repeat, EQ, and PL toggles |
| `posbar.bmp` | 307x10 | position/seek slider track and thumbs |
| `volume.bmp` | 68x433 | 28-frame volume bar and thumbs |
| `balance.bmp` | 68x433 | 28-frame balance bar and thumbs |
| `playpaus.bmp` | 48x9 | play/pause/stop and working indicators |
| `monoster.bmp` | 56x24 | stereo/mono indicators |
| `numbers.bmp` | 90x13 | 9x13 time digits |
| `text.bmp` | 155x18 | 5x6 bitmap font sheet |
| `pledit.bmp` | 280x186 | playlist editor chrome, shade bar, and popup menus |
| `eqmain.bmp` | 275x315 | equalizer chrome, 28 slider frames, graph |
| `eq_ex.bmp` | 275x56 | equalizer shade bar and mini sliders |
| `pledit.txt` | — | playlist text/background colors |
| `viscolor.txt` | — | 24-entry visualizer palette |

The palette and layout are original to this project. Do not add downloaded
Winamp skins here; keep those in a gitignored local folder.
